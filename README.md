# Sure Sound Entertainment – booking site

The public booking link for Sure Sound Entertainment. Netlify publishes this repository automatically.

- `index.html` shows the booking form (a Google Apps Script web app on keith.reynolds76@googlemail.com) full screen, without the Google banner.
- Live at https://suresoundentertainment.netlify.app (terms at /terms).
- `/terms` shows the Terms & Conditions.
- The booking system itself (Google Sheet, calendar, emails) lives in the "Sure sound bookings" sheet → Extensions → Apps Script.
  Publish code changes there with Deploy → Manage deployments → MAIN booking link → pencil → New version, so this link never needs changing.
